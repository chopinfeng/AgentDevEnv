设备分层与工具层

MCU 不做 Agent host —— ESP32 上 260K 参数模型约 19 tok/s，没有工具调用能力。设备负责感知与执行，Agent 循环留在云端。设备能力、MCP 服务器与 Skills 汇聚成同一份工具集，交给任意框架。

设备方言二选一：min 是自定义极简帧，ESP32 固件约 200 行、不实现 JSON-RPC；mcp 是把 JSON-RPC 包在信封里，与 xiaozhi-esp32 同款做法，可直接接入已在跑 Espressif mcp-c-sdk 的设备。
