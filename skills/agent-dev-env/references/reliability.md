# 可靠性工程

Agent 比普通服务多两类失败：**动作有副作用且可能重复**，**循环可能不收敛**。下面按会咬人的顺序排。

最成体系的参考是 AWS Well-Architected Agentic AI Lens（2026-06），它的成熟度模型与「常见问题」部分基本厂商中立，不用 AWS 也值得逐条对照。链接见 `sources.md`。

## 循环护栏

Agent 会因为工具报错、目标理解偏差而反复重试同一步。**必须有硬上限**：

- 单回合步数上限（OpenAI Agents SDK 的 `max_turns` 默认 30，超限抛异常）
- 输入护栏（模型调用前）与输出护栏（返回前），命中即中断整个运行

没有上限的代价是账单和延迟同时失控，且现象是「卡住」而非报错，很难第一时间发现。

## 幂等

**有副作用的操作必须幂等。** Agent 会重试——框架重试、用户重试、你自己的退避重试。不幂等就意味着重复下单、重复发消息。

参考 Stripe 的幂等键语义：**首次请求的状态码与响应体被保存，无论成功还是失败**；后续同键请求返回同一结果，包括 500。这一点常被忽略——只缓存成功响应的话，失败请求重试时仍会重复执行。

多步工作流里**幂等键要向下传播**，并传给原生支持幂等的外部系统。

## 熔断与恢复探针

熔断本身好写，**难在自动恢复**。AWS 点名的高频故障：

> 自动切断在故障时打开，但因为没有恢复探针而永远不关闭，导致系统早已恢复、能力却长期降级。

所以熔断必须配一个定期探测 + 自动重新启用的机制，否则就是把「短时故障」变成「永久降级」。

## 能力开关

**运行时能关停单个能力，不需要重新部署。** 出问题时的第一反应应该是关掉那个工具，而不是紧急发版。

反模式：关闭某个能力需要改代码重新部署——事故期间这个流程太慢。

## 回退路径

每个外部依赖都要想清楚：它挂了，Agent 是降级还是全盘失效？

常见错误是**把遗留系统当作云服务的可靠性来假设**，于是没写回退。内网的老接口比公有云更容易挂。

## 人机协同（HITL）

**监督强度应当匹配动作的风险与可逆性**——只读查询不需要审批，转账和删除需要。不要一刀切。

实现上用持久化执行框架的中断-恢复（LangGraph 的 `interrupt()`/`Command(resume=...)`、Temporal 的 Signal、Cloudflare Workflows 的等待外部事件）。

### LangGraph interrupt 的四个坑

这几个是官方明列的，每个都会造成难查的 bug：

1. **恢复时整个节点从头重跑**，不是从 `interrupt()` 那一行继续——之前的代码会再执行一次。所以 `interrupt()` 之前只能放**幂等操作**，非幂等的移到之后
2. **不要用裸 `try/except` 包住 `interrupt()`**——它靠抛异常实现暂停，会被吃掉
3. **不要在节点内用 `while True` 循环包 `interrupt()`**——每次恢复都会重放此前所有循环轮次，指数级重复。校验失败应把问题写进 state，用条件边跳回来
4. **`interrupt()` 调用顺序必须稳定**——resume 值按下标配对，条件性跳过会打乱配对

审批模式可以把 `interrupt()` 放进**工具函数本身**，从而对 LLM 发起的每次工具调用做执行前审批，并允许人工编辑参数。

## 演练

故障注入进 CI/CD，定期做 game day。Agent 的失败模式（工具超时、模型返回格式错误、上下文超限）在正常测试里遇不到，只能主动注入。

## 上线前对照

**没有一份被行业公认的 agent 上线检查清单。** 声称给出「权威 checklist」的单篇文章多数是内容农场。下面这份是从有出处的材料缝合的，出处见 `sources.md`：

| 维度 | 检查项 |
|---|---|
| 边界 | 每个 Agent 有显式作用域；护栏不随输入变化 |
| 权限 | Agent 有独立身份、最小权限、强认证 |
| 输入输出 | 上线前有输入校验与输出过滤 |
| 可追溯 | 能完整重建任意一次执行 |
| 评估 | 有测试与评估框架，**评轨迹不只评终答** |
| CI 门禁 | 每个 PR 跑评估；**配对比较 + 置信区间**判定真回归，不用单次分数 |
| 人类监督 | 分级监督，强度匹配风险与可逆性 |
| 中断恢复 | 有 checkpointer；`interrupt()` 前只放幂等操作 |
| 幂等 | 有副作用的操作全部幂等；幂等键向下传播 |
| 熔断 | 自动切断 **+ 恢复探针** |
| 回退 | 每个外部依赖有 fallback |
| 能力开关 | 运行时可关停单个能力，无需重新部署 |
| 循环护栏 | 步数上限 + tripwire |
| 成本 | Agent 级成本追踪；token 突增作为告警信号 |
| Prompt 发布 | 版本不可变 + 标签指针；回滚 = 移标签 |
| 安全 | 对照 OWASP LLM Top 10，尤其 **LLM06 Excessive Agency**（Agent 权限过大）与 **LLM10 Unbounded Consumption**（资源耗尽） |
